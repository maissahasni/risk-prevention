🛡️ Risk Prevention AI System

An AI-powered Risk Prevention Platform designed to detect workplace risks and improve worker safety using machine learning and computer vision.

This system analyzes safety conditions and helps prevent accidents before they happen.

📦 Installation
1. Clone Repository
git clone https://github.com/maissahasni/risk-prevention.git
cd risk-prevention
Install Frontend Dependencies
npm install

Run frontend:

npm run dev
Run Backend
cd backend
python app.py
Run AI Models

Example:

cd worker_safety_model
python model.py
